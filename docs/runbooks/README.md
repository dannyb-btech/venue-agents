# Runbooks

Write each runbook when its task introduces the failure mode. Format: symptoms, impact, diagnosis
(queries, dashboards), fix, prevention.

| Runbook | Written in task |
| --- | --- |
| OAuth token expired / revoked for a venue connection | P0-14 |
| Sync worker failing or falling behind | P0-14 |
| Bad draft sent to a client or supplier | P1-09 |
| Claude rate limit / quota exhaustion at peak | P3-02 |
| Cross-tenant data exposure suspected (incident response) | P1-09 |
| Moving a venue between stamps | P3-01 |
